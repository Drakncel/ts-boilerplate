### Description

This is a FullStack Typescript boilerplate for reference and learning.

It is currently a link shortening app but that is subject to change.

Frontend :
- Vite
- Tailwind + Shadcn
- TanStack Query

Backend :
- Hono (with proxy)
- Zod
- SQLite

### How to run

In both /frontend and /backend :

```
npm install
npm run dev
```
